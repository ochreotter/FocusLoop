# FocusLoop 1.0.2

## 新機能
- アプリ内でGitHub Releasesの最新バージョンを確認できます。
- 更新のダウンロード・検証・インストール・再起動に対応しました。
- 更新失敗時は旧バージョンへの復元を試みます。

## 改善
- 設定画面のプルダウンと時間入力欄で、ホイールによる意図しない変更を防止しました。
- アプリ内の日本語メッセージとツールチップを丁寧な表現に統一しました。

## ダウンロード
`FocusLoop-Windows.zip` をダウンロードし、展開した `FocusLoop` フォルダー内の `FocusLoop.exe` を起動してください。

**Full Changelog:** https://github.com/ochreotter/FocusLoop/compare/1.0.0...1.0.2
