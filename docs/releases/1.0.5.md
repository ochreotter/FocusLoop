# FocusLoop 1.0.5

## 修正内容

- フェーズ切り替え時に、ウィンドウが移動した直後に前フェーズの文字サイズ・デザインが一瞬見える問題を抑制しました。
- 表示位置・サイズ・Simple/Modern表示・最前面設定が変わる場合は、オーバーレイを一時的に非表示にした状態で新しい設定とジオメトリを反映し、新しい描画を準備してから再表示します。
- 「非表示」フェーズから表示フェーズへ移る際も、表示位置を確定してからウィンドウを表示します。
- 通常のカウントダウン更新や色の変更では不要な非表示・再表示を行いません。
- Windows/QtのUI回帰テストを追加しました。

※ Windowsデスクトップの描画合成タイミングは端末・環境によって異なるため、CIはウィンドウ更新の順序を確認します。
