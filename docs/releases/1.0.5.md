# FocusLoop 1.0.5

## 変更内容

- フェーズ切り替え時の表示の乱れを減らすため、ウィンドウの更新タイミングを調整しました。
- 表示位置・サイズ・標準表示／Simple表示・最前面設定が変わるときは、オーバーレイを一時的に非表示にして新しい設定と位置・サイズを反映し、再表示する処理に変更しました。
- 「非表示」フェーズから表示するフェーズに切り替わるときも、位置を確定してから表示します。
- 通常のカウントダウン更新や色の変更では、不要な非表示・再表示を行わないようにしています。
- Windows／QtのUI回帰テストで、ウィンドウ更新処理の順序を検証しました。

## 既知の問題

- **1.0.5でも、Windows環境ではフェーズ切り替え中に前のフェーズの表示が一瞬別の位置に現れる現象が残っています。** 例：右上・80ptから中央・300ptへの切り替えで、直前の表示が中央付近に一瞬見える場合があります。
- CIで確認できるのはQtの処理順序であり、Windowsデスクトップの描画合成による一瞬のちらつきまでは検証できていません。引き続き原因を調査します。
