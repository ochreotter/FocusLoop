# FocusLoop 1.0.6

## 改善内容

- **フェーズ切り替え時の表示の乱れを軽減**：表示位置・サイズ・標準／Simple表示・最前面設定が異なるフェーズへ移るとき、旧オーバーレイのウィンドウを移動・リサイズせず、次のフェーズ用に別のウィンドウを正しい位置とサイズで生成してから切り替えるように変更しました。
- **設定画面の初期縦幅を拡大**：「展開したフェーズ2個＋折りたたんだフェーズヘッダー1個」が収まる高さをウィジェットの実寸から計算します。画面が小さいときは利用可能な高さを上限にして、必要に応じて縦スクロールできます。
- 設定画面は従来どおり幅850px、起動時の展開状態も変更しません（現在のフェーズだけを展開）。
- 通常の秒更新ではオーバーレイを作り直さず、タイマーや保存済みのフェーズ設定も維持します。

## 検証・注意点

- 「右上80ptのFocus → 中央300ptのBreak」の切り替え、逆方向への移動、通常のタイマー更新、設定画面の高さ、Windows版ビルドを自動テストで検証しました。
- Windowsの実際のデスクトップ合成による一瞬のちらつきはCIのオフスクリーンテストだけでは完全に再現できないため、実機でも表示を確認してみてね。
