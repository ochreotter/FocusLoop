# FocusLoop 1.0.0（改訂版）

従来のフェーズ切り替え表示・設定画面の改善を維持し、Windows配布パッケージのQt構成とライセンス案内を見直しました。

## Windowsでの起動

`FocusLoop-Windows.zip` を新しいフォルダーへ展開し、`FocusLoop.exe` を起動します。EXEからDLLやプラグインを移動しないでください。

**旧配布版からの移行:** 旧版のタイマーを終了してから、改訂版を別フォルダーに展開して起動してください。公開バージョンを1.0.0に戻すため、旧配布版からはアプリ内の自動更新では移行できません。

## 同梱ライブラリの対応ソース

同じReleaseのAssetsにある `qt-everywhere-src-6.12.0.tar.xz` と `pyside-setup-everywhere-src-6.12.0.tar.xz` を参照してください。ハッシュは `Qt-PySide6-SHA256SUMS.txt` に記載しています。著作権・ライセンスおよび互換ライブラリへの交換手順はWindows ZIP内に同梱しています。
