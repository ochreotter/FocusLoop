# FocusLoop 1.0.0

Windows向けの背景が透明な繰り返しタイマーです。

## 主な機能

- 作業中45分・休憩中15分の繰り返しタイマー。フェーズの追加・削除・並べ替えにも対応
- フェーズごとに色、グラデーション、文字サイズ、不透明度、位置、最前面、非表示、Simple表示を設定可能
- 残り時間の円形ゲージ、ループ数表示、システムトレイからの操作、通知、一時停止・再開
- 日本語・英語の切り替えと、設定の自動保存
- GitHub Releasesを使ったアプリ内アップデート（更新確認、ダウンロード、検証、再起動、失敗時の復元）
- 設定画面でのホイールによる意図しない値の変更を防止
- アプリ内の日本語メッセージ・ツールチップを丁寧な表現に統一

## ダウンロード

`FocusLoop-Windows.zip` をダウンロード・展開し、`FocusLoop` フォルダー内の `FocusLoop.exe` を起動してください。DLLを含むフォルダー全体を保持してください。

※ 自動更新はWindows配布版のみ対応しています。インストール先の親ディレクトリへの書き込み権限が必要です。
